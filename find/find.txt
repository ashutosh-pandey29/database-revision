find() = Returns all matching documents in the form of a cursor or array.


====find all 
db.student.find(); OR db.student.find({});

== find student enrolled in BCA
db.student.find({course:"BCA"});

==Find students whose age is greater than **18**

db.student.find({ age: { $gt: 18 } });


===Find students using both age and course conditions

db.student.find({
  age: { $gt: 20 },
  course: "MA"
});

db.student.find({
  $and: [
    { age: { $gt: 20 } },
    { course: "MA" }
  ]
});



====Find the latest **5 inserted** students

db.student.find().sort({_id:-1}).limit(5);
db.student.find().sort({createdAt:-1}).limit(5);


== find one
========

db.student.findOne({});
